# Design System & Aesthetic Tokens

## 1. Color Palette

### Light Canvas (Daylight Minimal)
* `--paper`: `#ffffff`
* `--ink`: `#000000`
* `--cream`: `#f5f5f5`
* `--line`: `#dcdcdc`
* `--rust`: `#333333`

### OLED Dark Canvas (Night Theme)
* `--paper`: `#000000` (True deep black)
* `--cream`: `#0c0c0c` (Elevated surface)
* `--line`: `#262626` (Subtle boundary)
* `--ink`: `#ffffff` (High contrast text)
* `--rust`: `#e0e0e0` (Neutral accent)

## 2. Typography Hierarchy
* **Headings**: *Playfair Display* (Editorial Serif, 600/700 weight).
* **Body & UI**: *DM Sans* (Clean geometric Sans-Serif, 400/500/700 weight).
* **Labels & Kickers**: 10px uppercase with `0.16em` letter spacing.

## 3. Layout Standards
* Max Container Width: `1240px`.
* Sticky frosted navigation header (`.header.inner-header`).
* Universal 15-page directory footer on all views.
